第 1 章 編譯器導論

1.1 什麼是編譯器

編譯器 (compiler) 是一種將高階程式語言轉換為低階機器語言的程式。這個轉換過程並非單純的字串取代，而是一連串精密的語法、語意分析與程式碼轉換。編譯器讓我們能夠用接近人類思考方式的語言撰寫程式，同時產生機器可以高效執行的指令。

  原始碼 (C/Python/Java)  ──→  編譯器  ──→  機器碼 (x86/ARM)
圖 1.1：編譯器的基本功能

1.2 編譯器的階段

典型的編譯器分為前後端，共七個階段：

  1. 詞法分析 (Lexical Analysis) — 將原始碼切割成記號 (tokens)
  2. 語法分析 (Syntax Analysis) — 根據文法建立語法樹
  3. 語意分析 (Semantic Analysis) — 型別檢查與符號綁定
  4. 中間程式碼生成 (Intermediate Code Generation) — 產生平台無關的中間表示
  5. 最佳化 (Optimization) — 改善程式效率
  6. 目標程式碼生成 (Code Generation) — 轉換為目標機器指令
  7. 符號表管理與錯誤處理 — 貫穿所有階段的支援功能

特性編譯器直譯器

第 2 章 詞法分析

2.1 詞法分析的角色

詞法分析器 (lexer / tokenizer) 是編譯器的第一個階段。它的任務是讀取原始碼字元串，將它們分組為具有語意意義的記號 (tokens)，並忽略空白與註解。

記號 (Token)：詞法分析的最小單位，由一個類別 (type) 和一個值 (value) 組成。
例如：Token(type='NUMBER', value=42)、Token(type='PLUS', value='+')

考慮以下 C 語言片段：

int sum = 42 + 13;

詞法分析器會產生以下記號串：

INT   ('int')
ID    ('sum')
ASSIGN ('=')
NUMBER (42)
PLUS   ('+')
NUMBER (13)
SEMI   (';')

2.2 正則表達式

正則表達式 (Regular Expression) 是描述字串模式的數學表示法，也是定義詞法規則的標準工具。

表達式匹配範例
a字元 a"a"
a|ba 或 b"a", "b"
aba 後接 b"ab"
a*零或多個 a"", "a", "aa", ...
a+一或多個 a"a", "aa", ...
a?零或一個 a"", "a"
[0-9]任一數字"0", "1", ..., "9"
.任一字元（除換行）"a", "Z", "3"

典型的詞法規則可用正則表達式定義如下：

NUMBER  -> [0-9]+
ID      -> [a-zA-Z_][a-zA-Z0-9_]*
PLUS    -> +
MINUS   -> -
TIMES   -> *
DIVIDE  -> /
ASSIGN  -> =
LPAREN  -> (
RPAREN  -> )
SEMI    -> ;
SKIP    -> [ \t\n]+    # 忽略空白

2.3 有限自動機

有限自動機 (Finite Automaton) 是正則表達式的等價計算模型，分為兩種：

不確定性有限自動機 (NFA)

NFA 允許同一個狀態對同一個輸入有多個轉移，或存在 ε 轉移（不需輸入即可轉移）。

確定性有限自動機 (DFA)

DFA 的每個狀態對每個輸入最多只有一個轉移，沒有 ε 轉移，執行效率較高。

Thompson 建構法：將正則表達式轉換為等價 NFA 的演算法。每個正則表達式操作（串聯、聯集、Kleene Star）都有對應的 NFA 建構模式。

2.4 Python 實作詞法分析器

以下是一個完整的詞法分析器實作，支援整數、識別字、基本運算子與括號：

# lexer.py -- 詞法分析器

import re
from dataclasses import dataclass
from enum import Enum, auto

class TokenType(Enum):
    NUMBER = auto()
    ID     = auto()
    PLUS   = auto()
    MINUS  = auto()
    TIMES  = auto()
    DIVIDE = auto()
    ASSIGN = auto()
    LPAREN = auto()
    RPAREN = auto()
    SEMI   = auto()
    EOF    = auto()

@dataclass
class Token:
    type: TokenType
    value: str
    line: int
    col: int
    def __repr__(self):
        return f"Token({self.type.name}, '{self.value}')"


class Lexer:
    """詞法分析器：將原始碼轉換為記號串"""

    _rules = [
        (r'[ \t\n]+',   None),
        (r'//[^\n]*',   None),
        (r'[0-9]+',     TokenType.NUMBER),
        (r'[a-zA-Z_][a-zA-Z0-9_]*', TokenType.ID),
        (r'\+',         TokenType.PLUS),
        (r'-',          TokenType.MINUS),
        (r'\*',         TokenType.TIMES),
        (r'/',          TokenType.DIVIDE),
        (r'=',          TokenType.ASSIGN),
        (r'\(',         TokenType.LPAREN),
        (r'\)',         TokenType.RPAREN),
        (r';',          TokenType.SEMI),
    ]

    def __init__(self, source: str):
        self.source = source
        self.pos = 0
        self.line = 1
        self.col = 1

    def error(self, msg: str):
        raise SyntaxError(f"{msg} at line {self.line}, col {self.col}")

    def next_token(self) -> Token:
        if self.pos >= len(self.source):
            return Token(TokenType.EOF, '', self.line, self.col)
        remaining = self.source[self.pos:]
        for pattern, tok_type in self._rules:
            m = re.match(pattern, remaining)
            if not m:
                continue
            value = m.group(0)
            tok = Token(tok_type, value, self.line, self.col)
            newlines = value.count('\n')
            if newlines > 0:
                self.line += newlines
                self.col = len(value) - value.rfind('\n')
            else:
                self.col += len(value)
            self.pos += len(value)
            if tok_type is None:
                return self.next_token()
            return tok
        self.error(f"Unexpected character: {remaining[0]!r}")

    def tokenize(self) -> list[Token]:
        tokens = []
        while True:
            tok = self.next_token()
            tokens.append(tok)
            if tok.type == TokenType.EOF:
                break
        return tokens


if __name__ == '__main__':
    code = """
    x = 42 + 13;
    y = x * 2;
    """
    lexer = Lexer(code)
    for tok in lexer.tokenize():
        print(tok)
輸出結果： 
Token(ID, 'x')
Token(ASSIGN, '=')
Token(NUMBER, '42')
Token(PLUS, '+')
Token(NUMBER, '13')
Token(SEMI, ';')
Token(ID, 'y')
Token(ASSIGN, '=')
Token(ID, 'x')
Token(TIMES, '*')
Token(NUMBER, '2')
Token(SEMI, ';')
Token(EOF, '')

關鍵設計要點：

  • 最長匹配原則：使用 re.match 按規則順序嘗試，先匹配到的優先
  • 空白與註解忽略：將對應的 token type 設為 None，遞迴跳過
  • 位置追蹤：記錄行號與列號，方便後續錯誤報告

第 3 章 語法分析

3.1 上下文無關文法

詞法分析產生的記號串缺乏結構資訊。語法分析器 (parser) 的任務是根據上下文無關文法 (Context-Free Grammar, CFG) 為記號串建立語法樹。

上下文無關文法由以下四個部分組成：
  • 終端符號 (Terminals)：記號的具體類型
  • 非終端符號 (Non-terminals)：語法結構的抽象名稱
  • 產生式 (Productions)：非終端 -> 符號序列
  • 起始符號 (Start Symbol)：一個特殊的非終端符號

一個簡單算術表達式的文法：

expr    -> term ((PLUS | MINUS) term)*
term    -> factor ((TIMES | DIVIDE) factor)*
factor  -> NUMBER | LPAREN expr RPAREN

這個文法描述了一個支援加減乘除與括號的表達式語言。例如 2 + 3 * 4 的推導過程：

expr
-> term PLUS term
-> factor PLUS term
-> NUMBER(2) PLUS term
-> NUMBER(2) PLUS factor TIMES factor
-> NUMBER(2) PLUS NUMBER(3) TIMES factor
-> NUMBER(2) PLUS NUMBER(3) TIMES NUMBER(4)

3.2 遞迴下降分析法

遞迴下降分析法 (Recursive Descent Parsing) 是最直觀的手寫剖析技術。每個非終端符號對應一個函數，函數之間互相遞迴呼叫。

左遞迴問題：文法規則如 expr -> expr PLUS term 會導致無窮遞迴。解決方法是將左遞迴改為右遞迴或使用疊代匹配。

3.3 LL(1) 分析法

LL(1) 是一種從左到右掃描、產生最左推導、只需一個前瞻記號的剖析方法。它需要計算兩個集合：

  • FIRST 集合：一個符號可以開始的所有終端符號
  • FOLLOW 集合：在文法中可能跟隨在一個非終端符號之後的所有終端符號

3.4 Python 實作剖析器

以下實作支援加減乘除與括號的遞迴下降剖析器：

# parser.py -- 遞迴下降語法分析器

from lexer import Lexer, TokenType, Token

class ASTNode:
    pass

@dataclass
class BinOp(ASTNode):
    left: ASTNode
    op: Token
    right: ASTNode

@dataclass
class Num(ASTNode):
    token: Token
    value: int

@dataclass
class UnaryOp(ASTNode):
    op: Token
    operand: ASTNode


class Parser:
    def __init__(self, lexer: Lexer):
        self.lexer = lexer
        self.current = None
        self._advance()

    def _advance(self):
        self.current = self.lexer.next_token()

    def _expect(self, *types: TokenType) -> Token:
        if self.current.type not in types:
            expected = ', '.join(t.name for t in types)
            raise SyntaxError(
                f"Expected {expected}, got {self.current.type.name} "
                f"('{self.current.value}') at line {self.current.line}"
            )
        tok = self.current
        self._advance()
        return tok

    def parse(self) -> ASTNode:
        return self.expr()

    def expr(self) -> ASTNode:
        node = self.term()
        while self.current.type in (TokenType.PLUS, TokenType.MINUS):
            op = self.current
            self._advance()
            right = self.term()
            node = BinOp(left=node, op=op, right=right)
        return node

    def term(self) -> ASTNode:
        node = self.factor()
        while self.current.type in (TokenType.TIMES, TokenType.DIVIDE):
            op = self.current
            self._advance()
            right = self.factor()
            node = BinOp(left=node, op=op, right=right)
        return node

    def factor(self) -> ASTNode:
        tok = self.current
        if tok.type == TokenType.NUMBER:
            self._advance()
            return Num(token=tok, value=int(tok.value))
        elif tok.type == TokenType.LPAREN:
            self._advance()
            node = self.expr()
            self._expect(TokenType.RPAREN)
            return node
        elif tok.type in (TokenType.PLUS, TokenType.MINUS):
            self._advance()
            operand = self.factor()
            return UnaryOp(op=tok, operand=operand)
        else:
            raise SyntaxError(
                f"Unexpected token: {tok.type.name} ('{tok.value}')"
            )


if __name__ == '__main__':
    code = "2 + 3 * 4"
    lexer = Lexer(code)
    parser = Parser(lexer)
    ast = parser.parse()
    print(f"AST: {ast}")

這個剖析器正確實現了運算子優先權：2 + 3 * 4 被剖析為 2 + (3 * 4) 而非 (2 + 3) * 4，因為 term 在 expr 中被呼叫，確保乘除法先被綁定。

第 4 章 語意分析

4.1 符號表

符號表 (Symbol Table) 是編譯器用來儲存識別字相關資訊的資料結構，包括：名稱、型別、作用域、記憶體位置等。

# symbol_table.py

@dataclass
class Symbol:
    name: str
    type: str       # 'int', 'float', 'char', etc.
    is_const: bool = False
    value: any = None

class Scope:
    def __init__(self, parent: 'Scope' = None):
        self.symbols: dict[str, Symbol] = {}
        self.parent = parent
    def define(self, symbol: Symbol):
        if symbol.name in self.symbols:
            raise ValueError(f"Duplicate symbol: {symbol.name}")
        self.symbols[symbol.name] = symbol
    def lookup(self, name: str) -> Symbol | None:
        if name in self.symbols:
            return self.symbols[name]
        if self.parent:
            return self.parent.lookup(name)
        return None


class SymbolTable:
    def __init__(self):
        self.global_scope = Scope()
        self._scopes = [self.global_scope]
    def enter_scope(self):
        self._scopes.append(Scope(self._scopes[-1]))
    def exit_scope(self):
        if len(self._scopes) > 1:
            self._scopes.pop()
    def define(self, symbol: Symbol):
        self._scopes[-1].define(symbol)
    def lookup(self, name: str) -> Symbol | None:
        return self._scopes[-1].lookup(name)

4.2 型別檢查

型別檢查器遍歷 AST，確保每個運算子的運算元型別正確：

class TypeChecker:
    def __init__(self, symbol_table: SymbolTable):
        self.symtab = symbol_table

    def check(self, node: ASTNode) -> str:
        if isinstance(node, Num):
            return 'int'
        elif isinstance(node, UnaryOp):
            operand_type = self.check(node.operand)
            if node.op.type == TokenType.MINUS and operand_type == 'int':
                return 'int'
            raise TypeError(f"Invalid unary operation")
        elif isinstance(node, BinOp):
            left_type = self.check(node.left)
            right_type = self.check(node.right)
            if left_type != right_type:
                raise TypeError(
                    f"Type mismatch: {left_type} vs {right_type}"
                )
            if node.op.type in (TokenType.PLUS, TokenType.MINUS,
                                 TokenType.TIMES, TokenType.DIVIDE):
                if left_type in ('int', 'float'):
                    return left_type
                raise TypeError(f"Invalid operand type: {left_type}")
            return left_type
        raise NotImplementedError(f"Unknown node: {type(node)}")

4.3 抽象語法樹

抽象語法樹 (AST) 與具體語法樹 (CST) 不同，AST 省略了不必要的文法細節（如括號、分隔符號），只保留程式語義結構。

特性具體語法樹 (CST)抽象語法樹 (AST)
節點數量多（包含所有文法符號）少（只保留語義資訊）
括號以節點形式存在以樹的結構隱含
用途語法分析階段語意分析及之後

第 5 章 中間程式碼生成

5.1 三地址碼

三地址碼 (Three-Address Code, TAC) 是一種接近機器指令但保持平台無關的中間表示法。每條指令最多包含一個運算子與三個運算元：

形式：結果 = 運算元1 運算子 運算元2

範例：
t1 = 2 + 3
t2 = t1 * 4
x  = t2

常見的三地址碼指令：

指令類型格式範例
算術a = b op ct1 = a + b
複製a = bx = t1
無條件跳轉goto Lgoto L1
條件跳轉if a relop b goto Lif x < 10 goto L2
函數呼叫param a; call fparam 42; call print
回傳return areturn t2

5.2 控制流圖

控制流圖 (Control Flow Graph, CFG) 以基本區塊 (basic block) 為節點、控制轉移為邊，是後續最佳化的重要基礎。

基本區塊 (Basic Block)：一段連續的中間碼，滿足：
  • 只有第一條指令可以被進入
  • 只有最後一條指令可以離開
  • 內部沒有分支或跳轉

5.3 Python 實作中間碼生成

# ir_gen.py -- 中間程式碼生成器

from dataclasses import dataclass

@dataclass
class TacInstr:
    op: str       # '+', '-', '*', '/', '=', 'goto', etc.
    arg1: any = None
    arg2: any = None
    result: any = None
    label: str = None

    def __repr__(self):
        if self.label:
            return f"{self.label}:"
        if self.op == '=':
            return f"  {self.result} = {self.arg1}"
        if self.op.startswith('goto'):
            return f"  {self.op} {self.arg1}"
        return f"  {self.result} = {self.arg1} {self.op} {self.arg2}"


class TacGen:
    def __init__(self):
        self.instrs: list[TacInstr] = []
        self.temp_counter = 0
        self.label_counter = 0

    def _new_temp(self) -> str:
        self.temp_counter += 1
        return f"t{self.temp_counter}"

    def _new_label(self) -> str:
        self.label_counter += 1
        return f"L{self.label_counter}"

    def _emit(self, **kwargs):
        self.instrs.append(TacInstr(**kwargs))

    def generate(self, node: ASTNode) -> str:
        if isinstance(node, Num):
            temp = self._new_temp()
            self._emit(op='=', arg1=node.value, result=temp)
            return temp
        elif isinstance(node, UnaryOp):
            operand = self.generate(node.operand)
            temp = self._new_temp()
            self._emit(op='-', arg1='0', arg2=operand, result=temp)
            return temp
        elif isinstance(node, BinOp):
            left = self.generate(node.left)
            right = self.generate(node.right)
            temp = self._new_temp()
            self._emit(op=node.op.value, arg1=left, arg2=right, result=temp)
            return temp
        raise NotImplementedError(f"Unknown node: {type(node)}")


if __name__ == '__main__':
    code = "2 + 3 * 4"
    lexer = Lexer(code)
    parser = Parser(lexer)
    ast = parser.parse()
    gen = TacGen()
    result = gen.generate(ast)
    print("三地址碼：")
    print(gen)
輸出：

  t2 = 2 + t1

第 6 章 最佳化

6.1 基本區塊

最佳化通常在基本區塊內或跨基本區塊進行。以下是將 TAC 指令劃分為基本區塊的演算法：

def build_basic_blocks(instrs: list[TacInstr]) -> list[list[TacInstr]]:
    leaders = set()
    leaders.add(0)
    for i, instr in enumerate(instrs):
        if instr.op == 'goto' or instr.op.startswith('if_'):
            leaders.add(i + 1)
    blocks = []
    current = []
    for i, instr in enumerate(instrs):
        if i in leaders and current:
            blocks.append(current)
            current = []
        current.append(instr)
    if current:
        blocks.append(current)
    return blocks

6.2 常數傳播與折疊

常數折疊 (Constant Folding) 在編譯時期計算常數表達式：

# 原始碼                    # 最佳化後
x = 2 + 3                  x = 5
y = x * 4                  y = 20

常數傳播 (Constant Propagation) 將已知的常數值傳遞到使用處：

def constant_fold(instrs: list[TacInstr]) -> list[TacInstr]:
    const_values = {}
    result = []
    for instr in instrs:
        arg1 = const_values.get(instr.arg1, instr.arg1)
        arg2 = const_values.get(instr.arg2, instr.arg2)
        if (isinstance(arg1, int) and isinstance(arg2, int)
                and instr.op in ('+', '-', '*', '/')):
            val = eval(f"{arg1} {instr.op} {arg2}")
            const_values[instr.result] = val
            result.append(TacInstr(op='=', arg1=val, result=instr.result))
        elif instr.op == '=' and isinstance(instr.arg1, int):
            const_values[instr.result] = instr.arg1
            result.append(instr)
        else:
            result.append(instr)
    return result

6.3 死程式碼消除

死程式碼消除 (Dead Code Elimination) 移除從未被使用的變數賦值：

def dead_code_elim(instrs: list[TacInstr]) -> list[TacInstr]:
    used = set()
    for instr in instrs:
        if instr.arg1 and isinstance(instr.arg1, str) and instr.arg1.startswith('t'):
            used.add(instr.arg1)
        if instr.arg2 and isinstance(instr.arg2, str) and instr.arg2.startswith('t'):
            used.add(instr.arg2)
    result = []
    for instr in instrs:
        if (instr.op == '='
                and isinstance(instr.result, str)
                and instr.result.startswith('t')
                and instr.result not in used):
            continue
        result.append(instr)
    return result

第 7 章 目標程式碼生成

7.1 指令選擇

指令選擇 (Instruction Selection) 是將中間碼映射到目標機器指令的過程。在 x86-64 架構上：

TAC 指令x86-64 組合語言
t = a + bmov rax, a; add rax, b; mov t, rax
t = a * bmov rax, a; imul rax, b; mov t, rax
t = amov rax, a; mov t, rax
if a < b goto Lcmp a, b; jl L

7.2 暫存器分配

暫存器分配決定哪些變數存放在 CPU 暫存器中、哪些存放在記憶體中。圖著色演算法 (Graph Coloring) 是最常見的方法：

  • 建立干擾圖 (interference graph)：若兩個變數的生命週期重疊，則在圖中相連
  • 用 K 種顏色（K 為可用暫存器數）對圖著色
  • 相鄰節點不能同色
  • 無法著色的變數溢出 (spill) 到記憶體

7.3 x86 程式碼生成

# codegen.py -- x86-64 組合語言產生器

class CodeGen:
    def __init__(self):
        self.asm = []
        self.reg_map = {}

    def _alloc_reg(self, temp: str) -> str:
        regs = ['rax', 'rbx', 'rcx', 'rdx', 'rsi', 'rdi']
        if temp in self.reg_map:
            return self.reg_map[temp]
        if len(self.reg_map) < len(regs):
            reg = regs[len(self.reg_map)]
            self.reg_map[temp] = reg
            return reg
        return f'[rbp-{len(self.reg_map) * 8}]'

    def generate(self, instrs: list[TacInstr]) -> str:
        self._emit('.intel_syntax noprefix')
        self._emit('.globl main')
        self._emit('main:')
        self._emit('push rbp')
        self._emit('mov rbp, rsp')
        self._emit('sub rsp, 64')
        for instr in instrs:
            self._gen_instr(instr)
        self._emit('mov rsp, rbp')
        self._emit('pop rbp')
        self._emit('ret')
        return '\n'.join(self.asm)

    def _emit(self, line: str):
        self.asm.append(f'  {line}')

    def _gen_instr(self, instr: TacInstr):
        if instr.op == '=':
            dest = self._alloc_reg(instr.result)
            if isinstance(instr.arg1, int):
                self._emit(f'mov {dest}, {instr.arg1}')
            else:
                src = self._alloc_reg(instr.arg1)
                self._emit(f'mov {dest}, {src}')
        elif instr.op == '+':
            dest = self._alloc_reg(instr.result)
            left = self._alloc_reg(instr.arg1)
            right = self._alloc_reg(instr.arg2) if isinstance(instr.arg2, str) else str(instr.arg2)
            self._emit(f'mov {dest}, {left}')
            self._emit(f'add {dest}, {right}')
        elif instr.op == '*':
            dest = self._alloc_reg(instr.result)
            left = self._alloc_reg(instr.arg1)
            right = self._alloc_reg(instr.arg2) if isinstance(instr.arg2, str) else str(instr.arg2)
            self._emit(f'mov {dest}, {left}')
            self._emit(f'imul {dest}, {right}')

第 8 章 實戰：TinyC 編譯器

8.1 TinyC 語言規格

TinyC 是 C 語言的最小子集，包含以下功能：

  • 變數宣告與賦值（僅支援 int 型別）
  • 算術表達式（+, -, *, /）與括號
  • if-else 條件分支
  • while 迴圈
  • print 內建函數（輸出整數）
  • 區塊作用域 { }

8.2 完整實作

TinyC 編譯器整合了前面所有章節的技術：

# tinyc.py -- TinyC 編譯器主程式

import sys
from lexer import Lexer, TokenType
from parser import Parser, ASTNode, BinOp, Num

# --- AST 節點擴充 ---

@dataclass
class VarDecl(ASTNode):
    name: str

@dataclass
class Assign(ASTNode):
    name: str
    value: ASTNode

@dataclass
class If(ASTNode):
    cond: ASTNode
    then_body: list[ASTNode]
    else_body: list[ASTNode] = None

@dataclass
class While(ASTNode):
    cond: ASTNode
    body: list[ASTNode]

@dataclass
class Print(ASTNode):
    expr: ASTNode

@dataclass
class Block(ASTNode):
    stmts: list[ASTNode]


class TinyCParser(Parser):
    def parse_program(self) -> list[ASTNode]:
        stmts = []
        while self.current.type != TokenType.EOF:
            stmts.append(self.parse_stmt())
        return stmts

    def parse_stmt(self) -> ASTNode:
        if self.current.value == 'int':
            return self.parse_decl()
        if self.current.value == 'if':
            return self.parse_if()
        if self.current.value == 'while':
            return self.parse_while()
        if self.current.value == 'print':
            return self.parse_print()
        if self.current.value == '{':
            return self.parse_block()
        return self.parse_assign()

    def parse_decl(self) -> VarDecl:
        self._advance()
        name = self._expect(TokenType.ID).value
        self._expect(TokenType.SEMI)
        return VarDecl(name=name)

    def parse_assign(self) -> Assign:
        name = self._expect(TokenType.ID).value
        self._expect(TokenType.ASSIGN)
        value = self.expr()
        self._expect(TokenType.SEMI)
        return Assign(name=name, value=value)

    def parse_if(self) -> If:
        self._advance()
        self._expect(TokenType.LPAREN)
        cond = self.expr()
        self._expect(TokenType.RPAREN)
        then_body = [self.parse_stmt()]
        else_body = None
        if self.current.value == 'else':
            self._advance()
            else_body = [self.parse_stmt()]
        return If(cond=cond, then_body=then_body, else_body=else_body)

    def parse_while(self) -> While:
        self._advance()
        self._expect(TokenType.LPAREN)
        cond = self.expr()
        self._expect(TokenType.RPAREN)
        body = [self.parse_stmt()]
        return While(cond=cond, body=body)

    def parse_print(self) -> Print:
        self._advance()
        self._expect(TokenType.LPAREN)
        expr = self.expr()
        self._expect(TokenType.RPAREN)
        self._expect(TokenType.SEMI)
        return Print(expr=expr)

    def parse_block(self) -> Block:
        self._advance()
        stmts = []
        while self.current.value != '}':
            stmts.append(self.parse_stmt())
        self._advance()
        return Block(stmts=stmts)


# --- 中間碼生成（擴充支援控制流） ---

class TinyCTacGen(TacGen):
    def generate_program(self, stmts: list[ASTNode]):
        for stmt in stmts:
            self.generate_stmt(stmt)
        return self.instrs

    def generate_stmt(self, stmt: ASTNode):
        if isinstance(stmt, VarDecl):
            pass
        elif isinstance(stmt, Assign):
            val = self.generate(stmt.value)
            self._emit(op='=', arg1=val, result=stmt.name)
        elif isinstance(stmt, If):
            else_label = self._new_label()
            end_label = self._new_label()
            cond = self.generate(stmt.cond)
            self._emit(op='if_false', arg1=cond, arg2=else_label)
            for s in stmt.then_body:
                self.generate_stmt(s)
            self._emit(op='goto', arg1=end_label)
            self._emit(label=else_label)
            if stmt.else_body:
                for s in stmt.else_body:
                    self.generate_stmt(s)
            self._emit(label=end_label)
        elif isinstance(stmt, While):
            start_label = self._new_label()
            end_label = self._new_label()
            self._emit(label=start_label)
            cond = self.generate(stmt.cond)
            self._emit(op='if_false', arg1=cond, arg2=end_label)
            for s in stmt.body:
                self.generate_stmt(s)
            self._emit(op='goto', arg1=start_label)
            self._emit(label=end_label)
        elif isinstance(stmt, Print):
            val = self.generate(stmt.expr)
            self._emit(op='print', arg1=val)
        elif isinstance(stmt, Block):
            for s in stmt.stmts:
                self.generate_stmt(s)


# --- 虛擬機器 ---

class TinyCVM:
    def __init__(self):
        self.vars = {}
        self.labels = {}
        self.pc = 0
        self.instrs = []

    def load(self, instrs: list[TacInstr]):
        self.instrs = instrs
        for i, instr in enumerate(instrs):
            if instr.label:
                self.labels[instr.label] = i

    def run(self):
        while self.pc < len(self.instrs):
            instr = self.instrs[self.pc]
            self.pc += 1
            if instr.op == '=':
                val = instr.arg1
                if isinstance(val, str) and val in self.vars:
                    val = self.vars[val]
                self.vars[instr.result] = val
            elif instr.op in ('+', '-', '*', '/'):
                left = instr.arg1
                right = instr.arg2
                if isinstance(left, str) and left in self.vars:
                    left = self.vars[left]
                if isinstance(right, str) and right in self.vars:
                    right = self.vars[right]
                self.vars[instr.result] = eval(f"{left} {instr.op} {right}")
            elif instr.op == 'if_false':
                cond = instr.arg1
                if isinstance(cond, str) and cond in self.vars:
                    cond = self.vars[cond]
                if not cond:
                    self.pc = self.labels[instr.arg2]
            elif instr.op == 'goto':
                self.pc = self.labels[instr.arg1]
            elif instr.op == 'print':
                val = instr.arg1
                if isinstance(val, str) and val in self.vars:
                    val = self.vars[val]
                print(val)


# --- 主程式 ---

def compile_and_run(source: str):
    lexer = Lexer(source)
    parser = TinyCParser(lexer)
    ast = parser.parse_program()
    gen = TinyCTacGen()
    instrs = gen.generate_program(ast)
    print("=== 三地址碼 ===")
    for i in instrs:
        print(i)
    print("\n=== 執行結果 ===")
    vm = TinyCVM()
    vm.load(instrs)
    vm.run()
